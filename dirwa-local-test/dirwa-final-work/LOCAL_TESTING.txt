DIRWA FURNITURE WEBSITE — LOCAL TEST

This ZIP is structured with package.json at the archive root. Extract it into a folder,
then open Command Prompt in that folder (the same folder where package.json is visible).

1. Confirm the project root:
   dir package.json

2. Install dependencies:
   npm install

3. Start the development server:
   npm run dev

4. Open the Local URL printed by Vite (normally http://localhost:5173).

5. Verify production compilation:
   npm run build

DEPLOY TO CLOUDFLARE PAGES
- Framework preset: Vite
- Build command: npm run build
- Build output directory: dist
- Root directory: / (project root)
- Node: 18+ recommended
